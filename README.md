# Vi Tiên Cát Lucky Wheel

Web app vòng quay may mắn dành cho chương trình khuyến mại tại **Vi Tiên Cát Spa – Ecopark**.

## Tính năng

- 100% lượt quay có quà, không có ô trượt giải.
- 5 phần thưởng với xác suất ngang nhau.
- Giao diện cao cấp phong cách spa: emerald, ivory và champagne gold.
- Responsive desktop/mobile trong một viewport, không cần cuộn trang.
- Hiệu ứng quay mượt bằng Motion và confetti khi trúng thưởng.
- Không cần backend; toàn bộ logic chạy phía client.

## Phần thưởng

1. Giảm 30% cho dịch vụ tiếp theo.
2. 01 buổi chăm sóc da cấp ẩm.
3. 01 buổi gội dưỡng sinh 60 phút.
4. 01 bộ Nail tay.
5. 01 buổi Gót Sen Hồng.

## Thể lệ

- Hóa đơn từ 200K trở lên được quay 01 lần.
- Thời gian chương trình: 20/08 – 02/09.
- Địa điểm: Vi Tiên Cát Spa – Ecopark.

## Chạy local

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
npm run preview
```
